\begin{highlights}
\item Controlled five-condition experiment (7,300 trials) varies weak peer count in LLM debate.
\item Correct-to-incorrect flip rate rises 5.0\%~$\to$~6.5\% as dumb peer count increases.
\item Asch conformity index confirms bandwagon mechanism: unanimous peers amplify flip rate.
\item GPT-4o-mini shows $-$2.0 pp accuracy drop in C3; Asch index reaches 0.172 in C4.
\item Confidence-weighted filtering fails: weak agents report high confidence in 99.5\% of trials.
\end{highlights}
