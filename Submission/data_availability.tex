\noindent\textbf{Data Availability Statement}

\medskip
\noindent
The experiment code and pipeline configuration files are available in a
private repository and will be made publicly available upon acceptance.
The raw trial-log data (7,300 rows, including per-trial answers, flip flags,
and confidence scores) and the derived metrics summary will be deposited in
a publicly accessible repository (e.g.\ Zenodo or the institutional data
archive) at the same time.

The benchmark datasets used in this study are publicly available:
\textit{MMLU-Pro} \citep{wang2024mmlupro} is available at
\url{https://huggingface.co/datasets/TIGER-Lab/MMLU-Pro};
\textit{GSM8K} \citep{cobbe2021training} is available at
\url{https://huggingface.co/datasets/openai/gsm8k}.

The language models accessed via commercial APIs
(\textit{DeepSeek-v4-flash}, \textit{GPT-4o-mini},
\textit{Llama~3.1~8B Instruct}, \textit{Gemma~3~4B Instruct})
are proprietary; their weights and API specifications are described in the
respective technical reports cited in the paper.
